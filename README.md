# Code Valley — friends beta

Your Claude Code sessions become cat farmers, and each repository becomes a little farm.

[Download beta.2](https://github.com/beapessoa/code-valley-releases/releases/tag/v0.1.0-beta.2) · [Installation guide](INSTALL.md) · [Report a bug](https://github.com/beapessoa/code-valley-releases/issues/new) · [Website](https://code-valley-website.vercel.app/)

This repository contains app downloads and tester instructions. The application source remains private. Downloads are public; this is an early, free, non-commercial friends test, not the wider product launch.

## Before downloading

- **Apple Silicon Mac** with Claude Code in terminal or Claude Desktop's **Code** environment. Ordinary Claude chat is not an integration. No Codex, Intel or Windows support in this beta.
- Native checks so far used **macOS 26.5.1**. The binary's build floor is 15.0, but older systems have not been validated. The initial landing advertises the tested version as its conservative requirement.
- **Ad-hoc signed, not notarized by Apple.** macOS can block the first launch. Read the [installation instructions](INSTALL.md) before deciding to open it. A local Gatekeeper assessment rejected this candidate; a successful downloaded installation is still to be recorded.
- Performance, Desktop, accessibility, crowded menu-bar and longer real-use checks are incomplete. Please start in a disposable repository; report installation failures, missing work, lost progress or unexpectedly high resource use.

No Code Valley account, developer tools or cloud sync are required. Updates are manual. See the [beta.2 notes](RELEASE-NOTES.md) for the package and known limits.

## A first test

1. Install, choose a cat and review the Claude hook preview before connecting.
2. Start a **new** Claude Code session in a disposable repository. Make normal edits and watch the farmer and crops.
3. When mature crops are harvested, check the collection notice and open the chest. Three mixed crop items buy a Garden bush; place it in a free slot.
4. Quit and reopen. Check that the farm, inventory and decoration remain. Try a second repository when convenient.
5. Tell Bea what was confusing or broken. A short first test is useful; it does not complete the longer beta validation.

## Feedback

Use [Issues](https://github.com/beapessoa/code-valley-releases/issues/new), or reply privately to Bea through the channel where she invited you. **GitHub issues are public.** Include app version, macOS, Apple chip, terminal/Desktop Code, steps and expected/actual behavior. For an installation warning, include its exact wording.

Settings → Logs → Review copy offers a redacted diagnostic preview. Review it before copying. Never post raw logs, prompts, transcripts, Claude settings, credentials, session IDs, private repository names/paths or screenshots of unrelated conversations. Send privacy concerns directly to Bea.
